# この `wordquest/` フォルダについて

**まだ消さないこと。**

アプリは WORD QUEST から **WORDRIA** に改名した。正式な規約・プライバシー
ポリシーは `/wordria/` にある。こちらは改名前のURLで、**App Store Connect に
登録されたままになっている**。消すと Apple がURLを見にきたときに404になり、
審査で落ちる。

## 2026-09-19：中身を `/wordria/` と同じものに揃えた

それまで、この2ファイルは改名前の内容のまま凍結してあった。審査中のURLを
動かさないため、という判断だった。

だが `wordquest/privacy.html` には

> **全解放(買い切り)** を購入すると広告は表示されなくなります。

と書いてあった。**実際は月額500円のサブスクで、事実と違う。**
サブスクの条件を正しく書くことはガイドライン3.1.2の要求事項なので、
古いまま置いておくほうが危ない。凍結の理由（URLを動かさない）は、
中身を正しくすることとは両立する。URLは動かしていない。

いまは `/wordria/` のファイルをそのままコピーしてある。中の
`<link rel="canonical">` は `/wordria/` を指したままにしてあるので、
検索エンジンには正本が `/wordria/` だと伝わる。

**`/wordria/` を直したら、ここにもコピーし直すこと。**

```
cp wordria/privacy.html wordquest/privacy.html
cp wordria/terms.html   wordquest/terms.html
```

## 片づける順番

1. App Store Connect と Play Console の
   プライバシーポリシーURL・利用規約URLを `/wordria/` に変更する
2. アプリを公開する
3. **そのあと**、このフォルダの2ファイルを
   `/wordria/` へのリダイレクトに置き換える（完全に消さない）

リダイレクトにしておけば、どこかに古いURLが残っていても壊れない。
