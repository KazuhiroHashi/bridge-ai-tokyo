# この `wordquest/` フォルダについて

**まだ消さないこと。**

アプリは WORD QUEST から **WORDRIA** に改名し、規約・プライバシーポリシーは
`/wordria/` に移した。こちらは改名前のURLで、**App Store Connect に
登録されたままになっている**。消すと Apple がURLを見にきたときに404になり、
審査で落ちる。

## 片づける順番

1. App Store Connect と Play Console の
   プライバシーポリシーURL・利用規約URLを `/wordria/` に変更する
2. アプリを公開する
3. **そのあと**、このフォルダの2ファイルを
   `/wordria/` へのリダイレクトに置き換える（完全に消さない）

リダイレクトにしておけば、どこかに古いURLが残っていても壊れない。

## 中身のちがい

`wordquest/privacy.html` は内容が古い。「全解放(買い切り)」と書いてあるが、
いまは月額サブスクなので事実と違う。`/wordria/privacy.html` が正しい。
そのままにしてあるのは、審査中のURLを動かさないため。
